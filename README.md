# 🛍️ Denim Store – E-Commerce Platform
> **Live Demo:** [denim-store-rose.vercel.app](https://denim-store-rose.vercel.app)

## 🛠️ Tech Stack

| Category | Technology |
| :--- | :--- |
| **Frontend** | React 19, TypeScript 6 |
| **UI Library** | Material-UI v9, Joy UI, Base UI |
| **State Management** | Zustand |
| **Forms & Validation** | React Hook Form + Zod |
| **Styling** | styled-components, Emotion |
| **Routing** | React Router v7 |
| **Build Tool** | Vite 8 |
| **Deployment** | Vercel |
---
## ✨ Key Features

- 🛒 Product catalog with grid/list views
- 🔍 Advanced filtering by category, size, color, price
- 🛍️ Shopping cart with quantity management
- 📱 Fully responsive (mobile, tablet, desktop)
- ✅ Form validation with Zod + React Hook Form
- 🏷️ State management with Zustand
